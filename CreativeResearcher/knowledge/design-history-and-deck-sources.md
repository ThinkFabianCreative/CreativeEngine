# Design history and deck reference sources

> CreativeResearcher global source notes. No client facts.

## Provenance

Mined on 2026-11-17 from two outside packages supplied by the user (an "Art Teacher" agent and a "Presentation Engine" skill, neither installed). The URLs come from the packages, which marked several as unverified. Check each before citing it, and record the access date.

## Rule for all of these

Access to look is not a right to reuse. For every reference record the source URL, creator, date (or "uncertain"), medium, what is observed vs inferred, and rights status (`research-only`, `public-domain-verified`, `licensed`, `permission-needed`, `unknown`). Reference images inform direction; they don't go into client deliverables without a verified right.

## Figma file review method (when a template is worth studying)

1. Open the original Community resource, confirm it's free and record license, creator and date.
2. Duplicate into a review workspace only if permitted.
3. Catalog distinct compositions; ignore palette-only variants.
4. Extract structure (slots, content limits, ratio handling) into `shared/knowledge/deck-layout-archetypes.md` as our own description. Never copy styling or assets, and never claim a layer-level inspection that didn't happen.
