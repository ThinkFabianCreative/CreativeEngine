# Three-Hour Brand Sprint: run sheet

Method: GV (Knapp, Melahn, Burka, Zeratsky). See `shared/frameworks/design-sprint.md` §3.
Who: Decider (usually the CEO or founder) plus up to about 6 people who shape the brand. Facilitator runs the clock and stays neutral.
Materials: sticky notes, thick markers, dot stickers, whiteboard or shared board, visible timer. Remote: one board frame per exercise.

Rule for every exercise: **write silently alone → share → vote or place → Decider decides.** Disagreement that does not resolve is recorded as OPEN.

| Time | Exercise | Steps | Output |
|---|---|---|---|
| 0:00 | Intro (10 min †) | Purpose: shared language for later brand decisions. Not a strategy. | |
| 0:10 | **20-Year Roadmap** (15 min) | Each person notes where the company is in 5, 10, 20 years. Share. Not a plan; a sense of the brand's lifetime. | Long view, in the team's words |
| 0:25 | **What, How, Why** (30 min) | Concentric circles. What we do → how we do it → why we exist. Each writes, shares, dot-vote per ring. Cut the Why discussion at time; don't extend. | One line each for What / How / Why |
| 0:55 | Break (10 min †) | | |
| 1:05 | **Top 3 Values** (25 min †) | Everyone lists values; cluster; dot-vote to three; then pick the **single most important** one. Push past generic (quality, integrity). | 3 values, 1 marked #1 |
| 1:30 | **Top 3 Audiences** (30 min) | List every audience; vote to three; rank them. | Ranked 3 audiences |
| 2:00 | **Personality Sliders** (20 min †) | Each person places a mark on: Friend ↔ Authority; Young & Innovative ↔ Mature & Classic; Playful ↔ Serious; Mass Appeal ↔ Elite. Discuss spreads; Decider sets final position. | One mark per slider, spread noted |
| 2:20 | **Competitive Landscape** (25 min †) | 2x2: Classic ↔ Modern (x), Expressive ↔ Reserved (y). Place competitors, then where the brand is now and where it should be. | Map with the brand's target space |
| 2:45 | Wrap (15 min †) | Read the one-page summary aloud. List OPEN items. | Summary page |
