# SprintFacilitator knowledge

Reusable, client-free templates. Copy a template into `projects/<client>/<project>/work/workshops/<date>-<name>/` and fill it there. Never write client facts into this folder.

Method and source status live in `shared/frameworks/design-sprint.md` and `shared/frameworks/discovery-and-lean-loop.md`. Timings marked † are the facilitator's judgment, not from a source.

| Template | Use |
|---|---|
| `sprint-brief-and-readiness.md` | Before scheduling: challenge, Decider, team, preconditions, format decision |
| `brand-sprint-agenda.md` | Three-hour Brand Sprint run sheet and output page |
| `design-sprint-agenda.md` | Design Sprint run sheet: 5-day original and 4-day 2.0 |
| `test-day-kit.md` | Recruitment screener, five-act interview guide, observer grid, pattern review |
| `brand-digital-growth-sprint/` | 1–2 day Brand + Digital Growth Sprint kit: agenda and exercises, client proposal language, internal pitch narrative |
| `sprint-output-and-handoff.md` | Decision log, results, evidence labels, handoff to brief-machine and creative-engine-director |
