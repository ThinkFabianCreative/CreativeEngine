# Test day kit

Five customers, one-on-one, about an hour each, plus one backup. The team watches from another room or call. Recording needs each participant's consent; the user arranges it. Store only what the project needs.

## 2. Five-act interview guide
Interviewer only. Neutral, curious, never selling. Rewrite each sprint question as something you can observe.

**Act 1: Friendly welcome (~5 min).** Thank them. "We're testing a design, not you. There are no wrong answers. Please be candid; you won't hurt our feelings." Consent for recording.

**Act 2: Context questions (~10 min).** Start easy, then move to the topic. How they do [task] today, what they use, what's annoying, last time they did it. Listen for their words.

**Act 3: Introduce the prototype (~2 min).** "Some things may not work; that's fine. Please think aloud as you go." Set the scene that matches the storyboard's opening ("Imagine you searched for… and saw this").

**Act 4: Tasks and nudges (~30 min).** One simple nudge at a time. Let them explore. Probe expectations before they click ("What do you expect to happen?"). Neutral follow-ups: "What are you thinking?", "What would you do next?", "Tell me more." If you ask a leading question, follow with an open one.

## 4. End-of-day pattern review (~1 h)
1. Everyone reads the grid silently and writes patterns on stickies.
2. Group patterns: positive, negative, neutral. A pattern seen with three or more of five is strong (convention, not statistics).
3. For each sprint question: **yes / no / unclear**, with the evidence.
4. Decider sets next steps: iterate, rumble again, build, or return to the brief.

Report: sample size, patterns, quotes. No percentages. Labels per the evidence rules (OBSERVED / DERIVED / ASSUMED).
