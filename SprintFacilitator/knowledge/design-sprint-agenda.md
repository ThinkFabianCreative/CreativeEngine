# Design Sprint: run sheet

Method: Knapp, Zeratsky, Kowitz, *Sprint* (2016); 2.0 compression by AJ&Smart. See `shared/frameworks/design-sprint.md` §4 and §4a.
Day length about 10:00–17:00. Times marked † are the facilitator's judgment. Devices off except during Lightning Demos and research.

## Original five days

### Monday: map and target
| Time | Step | Notes |
|---|---|---|
| 10:00 | Intro, roles, rules (15 min †) | |
| 10:15 | **Long-term goal** (15–30 min †) | "Why are we doing this? Where do we want to be in 6 months, a year, 5 years?" Top of whiteboard. |
| 10:45 | **Sprint questions** (30 min †) | Prompts: what must we answer; to reach the goal what has to be true; imagine we failed, why? Rewrite each assumption as a "Can we / Will customers…?" question. |
| 11:15 | **Map** (30–60 min) | Actors left, ending right, words and arrows, 5–15 steps. Keep asking "does this look right?" |
| 12:15 | Lunch | |
| 13:15 | **Ask the Experts** (~30 min each) | Strategy (Decider first: success, advantage, biggest risk), voice of the customer, how things work, previous efforts. Per expert: intro sprint → 2-min whiteboard tour → "tell us everything" → reporter questions ("Why?", "Tell me more", "Where are we wrong?") → fix whiteboards. |
| (during) | **How Might We notes** | Silent, one per sticky, "HMW" top-left, thick marker. |
| 15:30 | **Organize HMWs** (~10 min) | Stick up at random, cluster by emerging theme, label, keep Misc. |
| 15:40 | **Vote HMWs** (10 min †) | 2 dots each, 4 for Decider, silently, against goal and questions. Winners go on the map. |
| 16:00 | **Pick target** (20 min †) | Decider picks the most important customer and moment on the map. Also pick which sprint questions matter most. |

### Tuesday: sketch
| Time | Step | Notes |
|---|---|---|
| 10:00 | **Lightning Demos** (3 min each, ~1 h) | Top one or two products per person, big screen, visible timer. Capture each big idea: quick drawing, headline, source. No debate. Aim for 10–20. |
| 11:00 | **Divide or swarm** (10 min †) | If the target spans parts (e.g. landing page, pricing, form), each person claims a part on the map. |
| 11:15 | **1. Notes** (20 + 3 min) | Copy goal, questions, HMWs, demo notes; review; circle the best. |
| 11:40 | **2. Ideas** (20 min) | Rough doodles, headlines, diagrams. Private. |
| 12:00 | Lunch | |
| 13:00 | **3. Crazy 8s** (8 min, can repeat) | Fold sheet into 8 panels, 60 s each, variations of one good idea. Also works for headlines. Private. |
| 13:15 | **4. Solution sketch** (30–90 min †) | Three panels on stickies, or full page for a single screen (homepage). Self-explanatory, anonymous, ugly OK, real words, catchy title. |
| (after) | Recruit | Confirm Friday's five customers (see `test-day-kit.md`). |

### Wednesday: decide and storyboard
| Time | Step | Notes |
|---|---|---|
| 10:00 | **Art museum** | Sketches on the wall. |
| 10:10 | **Heat map** (15 min †) | Silent; dot stickers on interesting parts; questions on stickies below. |
| 10:25 | **Speed critique** (3 min per sketch) | Facilitator narrates, team calls out standouts, scribe captures big ideas; creator reveals and adds what was missed last. |
| 11:30 | **Straw poll** (10 min †) | Each person one dot, silently. |
| 11:40 | **Supervote** | Decider places 3 special dots. Winners → prototype. "Maybe later" board for the rest. |
| 12:00 | **Rumble or all-in-one** | If winners conflict, Decider chooses: test both, or combine. |
| 13:00 | **Storyboard** (rest of day) | Whiteboard grid, 5–15 frames. Opening scene where the visitor really arrives (ad, search result, email). One person draws; Decider arbitrates; use existing ideas only. Enough detail for Thursday without questions. |

### Thursday: prototype
| Time | Step | Notes |
|---|---|---|
| 10:00 | Assign roles; split storyboard by Maker | Makers, Stitcher, Writer, Asset collector, Interviewer (writes script, doesn't build). |
| 10:15 | Build | Fake it; Goldilocks quality. Figma for web (see `format-prototyping` record). Real copy only. |
| 15:00 | **Trial run** | Stitcher walks it against the storyboard; team and Decider check it against the sprint questions. Fix. |
| 16:30 | Final check; Interviewer rehearses | |

### Friday: test
See `test-day-kit.md`. Five interviews (~1 h each), team watches remotely, grid notes, end-of-day pattern review with the Decider.

## Design Sprint 2.0 (four days)
Full team needed only for days 1–2. Exact 2.0 minute timings unverified.

| Day | Morning | Afternoon |
|---|---|---|
| 1 | Expert interviews + HMW, long-term goal, sprint questions, map, vote target | Lightning Demos (~1 h), four-step sketch (~1.5 h) |
| 2 | Art museum, heat map, speed critique, straw poll, supervote | User test flow (5–6 steps, each person drafts, vote), then storyboard (~8 frames) |
| 3 | Prototype (makers only) | Trial run with Decider |
| 4 | Five interviews | Pattern review and next steps |
