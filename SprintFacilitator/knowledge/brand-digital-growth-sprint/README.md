# Brand + Digital Growth Sprint (template kit)

Reusable, client-free. Holds no client facts. Copy into `projects/<client>/<project>/work/workshops/<date>-growth-sprint/` and fill it there. `[CLIENT]`, `[N YEARS]` and similar are placeholders.

| File | Audience | Use |
|---|---|---|
| `01-workshop-agenda-and-exercises.md` | TRAFFIK team running the sprint | Readiness, pre-work, 1-day and 2-day run sheets, board setup, exercises, Blueprint structure, evidence rules |
| `02-client-proposal-language.md` | Client (edit before sending) | Proposal sections positioning the sprint and its outcomes |
| `03-internal-pitch-narrative.md` | TRAFFIK leadership | How the sprint can lead to further workstreams, and the integrity line |

Method sources: `shared/frameworks/design-sprint.md` (Brand Sprint, Design Sprint), `shared/frameworks/discovery-and-lean-loop.md` (LUMA methods, Lean Canvas, evidence chain), `shared/frameworks/selling-the-work.md` (defense and honesty limits). Timings marked † are facilitator judgment, not from a source.

Status: draft V1 template. Not yet run with a client. Proposal language (02) should go through `word-smither` before external use if it is to carry TRAFFIK's voice.
