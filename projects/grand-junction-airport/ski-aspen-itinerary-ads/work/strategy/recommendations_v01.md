# Recommendations: Ski Season – Aspen Itinerary Ads (v01, 2026-10-08)

CLIENT: Grand Junction Airport / GJRASA · PROJECT: ski-aspen-itinerary-ads
FROM: creative-engine-director, based on normalized-brief_v02.md. These are recommendations, not approved decisions. Claim limits in brief §9 apply throughout.

## 1. Strategy
1. **One idea, four itineraries.** Use a single platform built on "the trip starts when you land" (R1 core promise, I3), with each audience getting its own route, not its own campaign. That's faster to make and builds memory.
2. **Make the itinerary the ad.** The product is the route, so show it: GJT pin → stop → Aspen. Each carousel card is one stop, so the format carries the idea.
3. **Win on what the drive is made of, not on minutes** (I1, I2). Never imply speed.

## 2. Targeting (resolves Q1 by recommendation)
4. Aim at **out-of-state skiers**, not Denver locals (I5). Priority 1: markets with confirmed direct service to GJT, once Q3 confirms them. Priority 2: high-volume ski origin markets that connect through DEN.
5. Exclude the Colorado Front Range from this hook. If GJRASA wants locals, that's a different message (catchment/leakage, S4), not this one.

## 3. Scope for 10/14 (resolves Q4/Q10 by recommendation)
6. **Deliver the full minimum first:** 4 audiences × one 3–5 card carousel at 1:1, plus a 9:16 Stories version built end-card-first.
7. **One shared 15s video with a swappable middle beat** (0–3 and 10–15 fixed, 3–10 per audience). That gives four cuts for roughly the cost of one. 4:5 and 16:9 only if time allows.
8. Proposed schedule: Thu–Fri concepts + stock pull · Mon internal review and client preview · Tue revisions · Wed 10/14 deliver.

## 4. Visual
9. **Open on snow on red rock** (I4). Rim Rock Drive or the Monument in snow is the frame that separates this from every white-peak ski ad. **Check stock availability today.** If there's no licensed winter red-rock shot, the idea needs a fallback. This is the biggest production risk.
10. **Route line as a system device:** a thin rust (#B85333) line with stop pins across the cards, as the brand's own graphic. Use the brand palette and Azo Sans; navy for type on light, rust bands as in the earlier work (visual reference only).
11. GJT brand in the first 3 seconds and on every end card (R1). Use the traced logo for comps only; real vector files before delivery (Q5).
12. Licensed stock only: build a shot list per stop (Monument snow, Palisade winter tasting room, Glenwood pool steam, Silver Queen Gondola, Aspen après) and pull it before concepting locks.

## 5. Copy
13. Banned: faster, quicker, shortcut, save time, hours back, no tunnel, no closures, fares, reliability. Allowed: start sooner, less driving, start relaxed, the scenic way in (C25 wording only after the map check).
14. Name places as destinations; no resort logos or pass offers.

## 6. Measurement (Q9)
15. UTMs per audience × format × version on flymyairport.com/to/GJT. Agree with the client that "click-out" = landing-page click to an airline booking, and report CTR to booking by audience. That proves which itinerary sells.

## 7. Client asks: send today
16. One email with five questions: target geos (Q1) · confirmed winter routes (Q3) · vector logo + brand guide + GJRASA 2026 brief (Q2/Q5) · one video or four (Q4) · how click-outs are tracked (Q9). Give defaults so silence doesn't stall us: "unless we hear otherwise by Fri, we'll proceed with…"
