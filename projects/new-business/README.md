# New Business

Pitch and RFP prospects that are not yet Traffik clients. Each prospect gets one folder here, laid out exactly like a client workspace (`projects/README.md`): its own `client/` identity record and one folder per pitch.

- Same isolation rules as any client. Nothing in one prospect's folder references another's, or any current client's.
- New-business briefs are usually thin. Record what the RFP or prospect actually says, mark the rest OPEN, and keep agency research labeled as agency research, never as client fact.
- If the pitch is won, the prospect folder moves to `projects/<client>/` as a whole. If it is lost, it stays here with its status set to LOST and the debrief recorded.
