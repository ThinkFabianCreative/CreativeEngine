# Donation pop-out lines, v01

```
CLIENT:   Miracles for Kids Charity
PROJECT:  website-rebrand
DATE:     2026-10-29
BY:       word-smither
```

Pattern: Outfit bold, one Caveat script word (sun yellow), marked *like this*. Limit about 26 characters at 17px bold in ~260px. Voice per P1/T5: 2–5 words, one highlight, "miracle" means the paid bill, never a cure.

## Monthly (confirmed, keep)
**Become a monthly *miracle.*** (26 chars)
It works because it describes the donor's role, not our need. No change.

## One-time
**Recommended: Be today's *miracle.*** (19 chars)
Pairs with "monthly" (a when, not a size), so the switch feels like one sentence changing tense. Shorter, so it sits comfortably on one line.

Alternates:
1. *Be someone's *miracle* today.* (27 chars, at the edge; test the fit). Warmer and more person-first, but it moves the script word to mid-line.
2. *Make a *miracle* today.* (23 chars). More active. "Make" leans toward the donor creating the outcome, so it's a bit less modest.

## Collapsed-bar button
**Recommended: Choose an amount** (16 chars). Keep it. It tells people exactly what happens next and stays neutral across both frequencies.
Alternate: *Give a miracle* (14 chars) if the bar needs the brand word, at some cost to clarity.
