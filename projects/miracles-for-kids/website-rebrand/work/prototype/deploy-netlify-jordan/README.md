# MFK, Jordan version: Netlify test build

Internal and NDA user testing only. Built from Figma "MFK Refinement (Copy)" frame 4040:1529 (MKF-JordanVersion), with Jordan's copy, sections and colors unchanged.

- noindex: robots meta, robots.txt and an X-Robots-Tag header (netlify.toml)
- To deploy, drag this folder (deploy-netlify-jordan) onto app.netlify.com/drop, or onto a new site's Deploys tab. index.html must sit at the top of the folder.
- Haboro Soft comes from Adobe Fonts kit scu3oyi; the domain must be allowed in that kit. Zooja Pro comes from the same kit. Cabin is the real face.
- The hero is a still frame. Jordan's design uses a video loop (HeroLoop3) that isn't in the repo.
