## What we want to learn

**The main question: are the new designs better than the live site?** Each new build (A, W, J) is judged against the existing site (E) on the measures below. Which new build wins comes second.

1. **Values fit.** Which version feels most like MFK.
2. **Fonts.** How the new type compares with the existing site's.
3. **Color.** How the new palette compares with the existing one.
4. **Families and video.** Which version makes it easiest to learn about families and to watch a video.
5. **Events.** Where people expect to find upcoming events, and whether they can.
6. **Giving.** Which version makes donating easy without feeling pushy.

This is a preference and comprehension test, not a conversion test. Nobody completes a payment.

## The four sites

| Code | Site | URL |
|---|---|---|
| **E** | Existing site (baseline) | https://miraclesforkids.org/ |
| **A** | Version A, Material 3 Expressive | https://boisterous-pothos-e638ac.netlify.app/ |

Participants hear neutral labels only ("Site 1, 2, 3, 4"), never "new" or "old," and never whose design it is.

Freeze W and J before the first session. If Jordan's Figma changes mid-test, the results stop being comparable.

## Who

Four groups, 3 to 5 people each (12 to 20 sessions in total). Five per group is enough to see the main patterns.

| Group | Who | Notes |
|---|---|---|
| Donors | Current and lapsed individual donors, and a corporate partner if possible | The main giving audience |
| Workers | Volunteers and event workers | Often the most engaged with events |
| Staff | MFK staff, not on the decision panel | Know the values; watch for loyalty to the current site |
| Families | Current or past families served | **Handle with care, see below** |

**Families.** A social worker or family liaison should invite them, never sales or fundraising staff. Make it clear that taking part has no effect on their support. Skip the giving task for families and ask only how the giving request *feels*. Offer a thank-you (a gift card) and let them stop at any time. Don't record faces without written consent.

All participants sign the NDA and a recording consent before the session.

## Order (counterbalancing)

Everyone sees **E first**, the live site as it is today, so it's the reference point every option is weighed against. A, W and J follow in a rotated order, so that none of the new options always benefits from going first or last among them.

| Rotation | Order after E |
|---|---|
| R1 | A, W, J |
| R2 | W, J, A |
| R3 | J, A, W |
| R4 | A, J, W |
| R5 | W, A, J |
| R6 | J, W, A |

Assign rotations in turn within each group (the first donor gets R1, the second R2, and so on).

## Session (50 minutes, moderated, remote or in person)

Use the participant's own device where possible. Mobile matters for families and workers, so aim for roughly half the sessions on a phone.

| Time | Part |
|---|---|
| 0:00–0:05 | Welcome, consent, warm-up: "How are you connected to Miracles for Kids?" |
| 0:05–0:13 | Site E, the live site: 5-second impression, tasks, ratings |
| 0:13–0:37 | Sites A, W and J in rotation order, about 8 minutes each, with the same tasks and ratings |
| 0:37–0:48 | Side-by-side comparison: values, fonts, color, head-to-head with the live site, final preference |
| 0:48–0:50 | Anything else, thank you |

### For each site

**1. First impression (5 seconds).** Show the top of the page for 5 seconds, then hide it.
- "What three words describe what you just saw?"
- "Who do you think this organization helps?"

**2. Tasks.** Read each one out, then ask the participant to think aloud. Note success, time and where they looked first.

| # | Task | Goal it serves |
|---|---|---|
| T1 | "Find a story about a family Miracles for Kids has helped, and tell me what you learned." | Families |
| T2 | "Find the video and start it." | Video |
| T3 | "When is the next event you could go to?" | Events |
| T4 | "Say you wanted to give $50 a month. Show me how you'd do it, and stop before payment." Families get a different prompt: "Where would someone go to donate?" | Giving |

**3. Ratings (1 to 5).** Ask these right after the tasks.

| Rating | Question |
|---|---|
| R-values | "This feels like Miracles for Kids." |
| R-trust | "I trust this organization with a donation." |
| R-type | "The text is easy to read and suits the organization." |
| R-color | "The colors suit the organization." |
| R-families | "It was easy to learn about the families." |
| R-events | "It was easy to find events." |
| R-give | "Giving felt easy." |
| R-pressure | "I felt pushed to give." (Reverse-scored. Low is good.) |

### Comparison at the end

Put all four sites side by side: tabs or printed screenshots of the top of each page.

**Values card sort.** Give the participant five cards drawn from MFK's own language: *Family is everything · Whole-family care · Transparency · Together · Help right now*. Ask them to place each card on the site that best shows it, then explain the hardest choice.

These values are inferred from MFK's language. There is no formal values statement (client/knowledge/organization-profile.md).

**Fonts.**
- Show the headline and a paragraph from E, A, W and J at the same size.
- "Which reads most like Miracles for Kids? Which is easiest to read? Which would you change?"

**Color.**
- Show each site's palette as a row of swatches next to a page screenshot.
- "Which feels warmest? Most trustworthy? Most like a children's charity, for better or worse?"

**Head-to-head with the live site.** Put each new site next to E, one pair at a time, in the participant's rotation order. Ask: "Is this one better, the same or worse than that one for Miracles for Kids? Why?" Ask about each of: overall, fonts, color, finding families and video, finding events, giving.

**Preference.**
- "If Miracles for Kids could only keep one, which should it be? Why?"
- "What's one thing from another site you'd steal for it?"

## How we'll read the results

**The headline result: does each new build beat E?**

| Measure | A new build "beats the live site" when |
|---|---|
| Ratings | Its median is higher than E's on R-values, R-type, R-color, R-families, R-events and R-give, and not worse on R-trust or R-pressure |
| Tasks | Task success on T1–T4 is equal to or better than E's |
| Head-to-head | More participants say "better" than say "worse" against E, overall and for each topic |
| Groups | It holds for donors and families, not just staff |

Report each new build against E in its own table, then compare the new builds with each other.

- **Preference:** the final pick, split by group. Donors and families may differ, and that matters more than the total.
- **Values fit:** the card-sort tally per site, plus R-values.
- **Fonts and color:** the comparison choices, plus R-type and R-color against E.
- **Usability:** task success for T1–T4 per site, and where people looked first for events and donating.
- **Giving balance:** R-give high **and** R-pressure low is the target. A site that scores well on giving but makes people feel pressured does not pass.
- **Quotes:** the reasons behind each preference, grouped by theme.

Twelve to twenty people show direction, not statistical proof. Report patterns and quotes, and don't treat averages as decisive.
