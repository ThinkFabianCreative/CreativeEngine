# Web inspiration sources

Where to look for web, type, motion and identity references. Global method: no client facts. Owners: `creative-researcher` (reference boards) and `design-champ` (craft). Source: a curated list the user shared on 2026-11-18. Links were not checked one by one; some will move or go paid.

How to use: pick sources by the job, screenshot what works, and note what is good about each one ("the spacing on this hero", not "I like this"). References dress the idea; they never replace it (Barry §1, `barry-concept-art-direction.md`). Never lift a client's look from another brand's site.

## Use with care

- **Prompt marketplaces** (MotionSites, Layers, SceneAI, Motionin, Vibe Prompts): paid and prone to the generic AI look (CLAUDE.md principle 10). Use them for reference, not for recipes.
- **System extractors** (DesignMD, Refero Styles, Firecrawl): use them to study a site's system, never to copy a look onto a client.
- **Claude skills on the list** (Jakub Krehel's skills, Refactoring UI, VibeCurb, Libraries.dev, Inspo MCP, Screenshot to Code): third-party, so each needs the CLAUDE.md review before install. Status lives in `DesignChamp/skills/README.md`.
