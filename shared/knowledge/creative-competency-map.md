# Creative Competency Map

> CreativeEngine shared knowledge. An audit instrument: which creative competencies the department covers, and where it doesn't. Maintained by `creative-engine-director`. Not a framework, not a scorecard, and not a to-do list.

## Provenance

- **Reference point:** Miami Ad School, *Catalog of Courses*, Volume 39 (August–December 2026), supplied by the user on 2026-09-17. Portfolio programs (Art Direction, Copywriting, Design), the FIU Creative and Strategy tracks, the Strategic Planning and Digital Media & Social Strategy boot camps, and the Creative Director Program.
- **What was taken:** the topic taxonomy only — which competencies an industry school treats as part of the job. Course codes are cited so a row can be traced back. No course description is reproduced here.
- **What the catalog is not:** a method source. Its entries name topics without teaching them. Nothing in a CreativeEngine framework should cite the catalog as the origin of a technique.
- **Scope:** global method. This file holds no client or project facts, and a gap here is never evidence about any client's work.

## How to use it

1. **To audit.** Before designing a new framework, skill or agent capability, check whether this map already records the competency, its status and where it lives.
2. **To route.** The WHERE column says which file carries a competency today, so a question about it goes to the right place.
3. **To re-audit.** When a framework or skill is added, update the affected rows and add an entry to the audit log.

A GAP is a fact, not an instruction. Whether a gap is worth closing is a separate decision, made against the root `CLAUDE.md` rule against framework maximalism. Several gaps below are deliberately left open.

### Status

| Status | Meaning |
|---|---|
| **COVERED** | A framework, agent definition or reviewed skill carries real method for it |
| **PARTIAL** | Touched by existing material, but without dedicated method, or only for one aspect |
| **GAP** | Nothing in CreativeEngine carries it |
| **PLANNED** | A registered planned framework will own it (root `CLAUDE.md` registry) |
| **EXECUTION** | Tool or production skill (software, camera, recording). Handled by skills or by humans, not by creative judgment frameworks |
| **OUT OF SCOPE** | A human, organizational or career competency an AI creative department does not exercise |

## Maintenance

- Update a row when its WHERE changes: a framework or skill is added, retired or reviewed.
- A new reference curriculum (another school, a competition's criteria, an agency's competency model) may be audited against this map. Add its references in a new column or a note, never replace the existing ones, and record it in the audit log.
- Keep rows at the level of a competency, not a course. Several courses often map to one row.
- Do not add client or project observations. A gap seen in one client's work is recorded in that project's `work/reviews/`.
