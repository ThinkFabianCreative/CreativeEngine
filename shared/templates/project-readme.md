# Project README starter

> CreativeEngine shared template. Generic and reusable; holds no client facts. Copy it to `projects/<client>/<project>/README.md`. Filesystem contract: `projects/README.md`.

How to use it:

- Delete any section the assignment does not need. Funnel, conversion, channel and education detail apply only where the assignment establishes them.
- Write only what the user or a source has supplied. Mark everything else OPEN or UNKNOWN; never fill a field by inference or from another client.
- Once `normalized-brief.md` exists, it is the briefing authority. Sections marked *summary* hold one or two lines and a link to the brief section, not a second brief. Where this README and the brief differ, the brief governs and this README is corrected.

Copy from the line below.
