# Shared frameworks

Frameworks are shared CreativeEngine intellectual infrastructure: how we think and judge. Any agent may consult them. Skills, which are how we do, are separate; see "Frameworks vs skills" in the root `CLAUDE.md`.

## Adding a framework

1. Add the file to this folder.
2. Register it as Active in the root `CLAUDE.md` registry, with its purpose, primary users and when to use it.
3. A new framework adds capability. It does not replace, supersede or consolidate an existing framework unless the user explicitly says so.
