# Agency context

Shared context for any Claude session working on CreativeEngine, on any machine. It used to live only in one machine's local Claude memory; it lives here now so every session starts from the same facts.

| File | Holds |
|---|---|
| [team.md](team.md) | Who is who at Traffik: creative, accounts, PM, media, leadership, reporting lines |

**Rules**
- This is agency context, not client knowledge. Facts about a client go in `projects/<client>/client/`.
- Update a file when a fact changes, and date it. Don't keep two versions of the same fact.
- No personal contact details, credentials or account sign-ins here.
