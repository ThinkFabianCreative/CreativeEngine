# Advertising repository research

Use available web search and browser tools to find and inspect relevant advertising campaigns. Default to Love the Work (https://www.lovethework.com/) unless the user specifies another repository. A skill supplies research instructions; it does not supply credentials or a searchable copy of the archive.

The primary purpose is to feed Creative Engine with evidence-backed advertising references. Search, open and read relevant ads; extract what makes each idea work and how its principle could inform the current brief. Originality checks are an optional mode, not the default outcome.

## Understand the search

Determine whether the user wants inspiration, award research, or a creative precedent check. Extract the brand/category, audience, medium, geography, date range and underlying creative mechanism from the brief. Ask only for missing constraints that materially affect the search; otherwise state reasonable assumptions.

For precedent checks, describe the idea in one sentence without brand names. Search the mechanism and execution as well as the category. For example, a ski technique manual used to teach hot-spring relaxation calls for searches about instruction manuals, technique diagrams, illustrated steps, sport-to-relaxation inversion, skiing, spas and travel.

Treat user-provided search inventories as supplied evidence and preserve their stated limits. If the user checked all listing pages but only read titles and categories, use that inventory to avoid repeating discovery; inspect selected creatives before assessing their mechanisms. A broad category such as Travel, Leisure, Retail, Restaurants may contain only restaurant work in a particular filtered result set. When the requested sector is absent, broaden to other festivals, years or keyword searches and disclose that scope change. Do not turn absence in one award listing into absence across the repository.

## Search and verify

- Start from a supplied repository URL and preserve its filters. Inspect visible entries and any pagination; do not assume the first page covers the archive.
- Use the repository's available search/filter controls and complementary domain-restricted web searches. Try exact phrases, synonyms, adjacent categories and broader years when appropriate. Record the actual scope searched.
- Open promising entry pages and full-campaign links when available. Inspect creative images, films or case descriptions before claiming visual or conceptual similarity. Search snippets and titles are leads, not proof of execution.
- If web text extraction omits creative assets, try the available browser tools to inspect the rendered page. For print ads, examine the image, headline, body copy, layout and brand/product role. For film, inspect accessible footage or a reliable transcript and explain which was inspected. Never present a case-film synopsis as direct observation of the film.
- Record campaign title, brand, agency, year, festival, category, award status and direct URL only when verified. Distinguish shortlisted work from award winners and individual executions from the full campaign. Consolidate duplicate category listings while preserving distinct executions.
- If content requires login, use an available user-authorized authenticated browser session. If access remains unavailable, explain the limitation and continue with public evidence. Do not bypass access controls or invent missing content.

## Assess relevance

Separate shared subject matter from shared creative mechanism and shared execution. Explain the particular overlap: visual device, central joke, headline structure, sequence, interaction or brand role. Label interpretation as interpretation. Avoid equating a similar topic with copying.

For an originality check, report close precedents, adjacent precedents and material differences. Never conclude that an idea is original simply because searches returned no match. Use wording such as: "No close precedent found within the sources and scope checked."

## Deliver the findings

For Creative Engine reference research, provide a compact reference card for each useful campaign:

- Verified title, brand, agency, year, medium, award details where available, and direct source URL.
- Evidence level: creative inspected, description inspected, or metadata only; specify accessible assets examined.
- What the ad actually shows and says, summarized in your own words. Mark illegible or inaccessible copy as unknown.
- Audience insight or tension, central idea, creative mechanism, visual device, copy approach and brand role. Distinguish observed facts from your interpretation.
- Why it is relevant to the current brief, the reusable principle, and one concrete direction Creative Engine could explore using that principle.
- Distinctive elements to avoid reproducing too closely, such as the original headline, composition or central visual joke.

Prefer a smaller set of inspected, useful ads over a long list of titles. Put metadata-only leads in a separate follow-up list; do not count them as analyzed creative references. Include adjacent-sector work when its mechanism is useful, clearly explaining the connection.

When the user asks to save or integrate references, inspect the Creative Engine project's applicable instructions and existing reference format first. Use that format and retain source URLs and evidence levels. Otherwise deliver the research in chat without inventing an application integration or claiming a persistent archive exists.

Return a focused shortlist suited to the request, ordered by relevance. For each result include verified identifying details, a direct source link, a short description of the idea and why it matters to the brief. Mark evidence as creative inspected, description inspected, or metadata only. Leave unavailable fields explicitly unknown.

For precedent checks, end with an evidence-based assessment of the closest overlap and concrete ways to make the proposed idea more distinctive. Include sources searched, filters/date range, access gaps and any incomplete pagination. Summarize creative work in your own words; link to originals instead of reproducing entire case studies.
